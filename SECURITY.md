# Reporting something sensitive

If you believe something published here reveals a vulnerability that is not yet
fixed, or identifies a party that asked not to be identified, do not open a
public issue.

Use GitHub's private vulnerability reporting on this repository, or contact the
maintainer through the address on the GitHub profile.

The first action is always the same: the case is taken down, then we talk. No
published case is worth an unfixed disclosure or a broken confidence.

## Scope of this policy

This repository contains write-ups, not software. There is no code to run, so
there is no software vulnerability to report — the cases themselves are the only
thing that can be wrong, and a wrong case is a correction, not a vulnerability.

Corrections are published with the date and the change. See the README.
